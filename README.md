# Geographic Information System REST Interface 
A Java-based Geospatial Full stack application developed as part of a university software engineering project. It provides REST APIs for geospatial queries, map rendering, and route computation. Contributed:
- Implemented Middleware Enpoints
- Wrote gRPC background communication between SpingBoot based middleware and OSM Backend
- Parsed and processed OpenStreetMap geospatial data (roads, amenities, land usage)
- Implemented map tile rendering, route calculation, and location-based spatial queries
- Built shortest-path routing using the Dijkstra's algorithm algorithm

# What I learned
- Designing and structuring scalable Java backend services
- Building RESTful APIs and backend communication layers
- Working with geospatial data, coordinate systems, and spatial queries
