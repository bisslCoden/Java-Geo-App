# Geographic Information System REST Interface

A Java-based full-stack geospatial application developed as part of a university software engineering project. It provides REST APIs for geospatial queries, map rendering, and route computation using OpenStreetMap data.

## Key Contributions
- Implemented middleware endpoints using REST APIs
- Built gRPC communication between the Spring Boot middleware and OSM backend
- Parsed and processed OpenStreetMap geospatial data (roads, amenities, land usage)
- Implemented map tile rendering, route calculation, and location-based spatial queries
- Built shortest-path routing using Dijkstra’s algorithm

## What I Learned
- Designing and structuring scalable Java backend services using Spring Boot and gRPC
- Building RESTful APIs and backend communication layers
- Working with geospatial data, coordinate systems, and spatial queries
